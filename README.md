# Planifolia

Мод для Fabric 1.21.11 (Java 21): дополнительные бинды клавиш/мыши на действия игры + профили.

## Сборка
```
./gradlew build        # Windows: gradlew.bat build
```
Готовый мод: `build/libs/moreculling_extra-1.0.0.jar` (не `-sources`). Кладётся в `mods/` вместе с Fabric API.
Для IntelliJ IDEA: открыть папку как Gradle-проект, запуск — задача `runClient`.

## Использование
Окно открывается сочетанием `O` + `P` (по положению клавиш, раскладка не важна). Семь вкладок:

**Бинды** — профили сверху (`<` `>` переключение, поле — имя, `+` новый, `-` удалить), 10 строк.
Левое окно: клик, потом нажать клавишу или кнопку мыши (Esc = очистить).
Правое окно: клик = следующее действие игры, Shift+клик = предыдущее.

**Клачи** — ты сам бросаешь эндер-жемчуг, мод бросает заряд ветра. Пока клач идёт, мышь заблокирована,
камера остаётся там, где был брошен заряд.
- Клач 90°: пёрл брошен строго вверх -> через «Пауза, мс» бросается заряд ветра.
- Клач 45° (spearmace): пёрл под 45° -> камера плавно опускается на «Ниже на, °» за «Поворот камеры, мс» -> заряд ветра.
- «Допуск угла» — насколько можно отклониться от нужного угла в момент броска пёрла.
- Время считается тиками по 50 мс: значение «мс» округляется до ближайшего тика (50, 100, 150...).

**Эксперимент** — вместо фиксированного «Ниже на» мод сам считает, куда бросить заряд, по реальному положению
твоего летящего пёрла. Срабатывает для пёрла под заданным углом вверх.

**Слот** — номер слота хотбара (1–9) с зарядом ветра или «Авто» (искать по хотбару). Обратно слот не переключается.

**Сворды** — рамка хитбокса вокруг игроков, пока дистанция до них от «от» до «до» блоков (по умолчанию 2.5–2.9).
- Дистанция считается от глаз до ближайшей точки хитбокса цели (так же, как досягаемость удара).
- «Только с мечом в руке» — рамка показывается, только если в основной руке меч.
- Цвет задаётся кодом RRGGBB (рядом показан образец). За стеной рамка не рисуется. Только вид от первого лица.

**Стрела** — предсказание полёта стрелы, когда в руках лук (идёт натяжение) или заряженный арбалет.
- Линия траектории рисуется всегда; красная грань блока — только если стрела во что-то попадает. Существа игнорируются.
- Рисуется в мире с проверкой глубины: сквозь стены не видно. Физика: pos += vel; vel *= 0.99 (в воде 0.6); vel.y -= 0.05; до 200 тиков.
- Настройки: вкл/выкл, толщина, цвет и прозрачность линии, цвет и прозрачность грани. Разброс не учитывается.

**Жемчуг** — пока в руке эндер-жемчуг и прицел наведён на игрока, рисуется траектория броска пёрла (от точки вылета)
и маркер в точке падения. Физика пёрла: скорость 1.5, vel *= 0.99 (в воде 0.8), vel.y -= 0.03; разброс не учитывается.
- «Учитывать игроков»: вкл — линия обрывается на игроке, в которого попадёт пёрл; выкл — только блоки.
- «Дальность прицела» — на каком расстоянии искать игрока по прямому лучу взгляда.

Конфиг: `config/moreculling_extra.json`. Свои бинды не регистрируются как KeyMapping, поэтому в «Управлении» их нет.

## Идентификаторы
- `id` мода (в `fabric.mod.json`): `moreculling_extra` — технический латинский идентификатор, пользователю не виден.
- Название в списке модов: `Planifolia`. Иконка: `assets/moreculling_extra/icon.png`.

## Сборка без установки Java
Залей проект в свой репозиторий на GitHub. Вкладка Actions -> build -> после завершения скачай `moreculling_extra-jar` (внутри jar без `-sources`).
